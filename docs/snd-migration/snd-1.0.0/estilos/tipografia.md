## 1. Descripción

### Familias tipográficas
- **Noto Sans** (`Aa`)
- **Patria** (`Aa`)

### Variables
- **Encabezado (H0):** Jerarquía de texto más alta, se ubica generalmente al inicio de la página y describe el contenido de la misma. Sólo puede existir un encabezado por página.
- **Título (H1):** Texto que marca la jerarquía máxima dentro de una sección. Límite de tamaño máximo en móvil (`H2`).
- **Título secundario (H2):** Texto que subdivide secciones después del título principal.
- **Subtítulo (SH0):** Texto de apoyo que explica o complementa títulos principales.
- **Subtítulo (SH1):** Texto que subdivide secciones después del título principal.
- **Cuerpo de texto (B1S):** Sus usos recomendados pueden enfocarse en dar énfasis sutil sin romper la jerarquía visual. Se utiliza principalmente en entrecomillados, menciones, títulos de obras, palabras extranjeras, conceptos clave o notas editoriales que deben resaltarse dentro del contenido.
- **Cuerpo de texto (B1IT):** Texto principal de lectura, utilizado para párrafos o descripciones.
- **Botones (CTA):** Texto que invita a realizar una acción dentro de un botón.
- **Enlace de texto:** Texto que invita a realizar una acción dentro de un párrafo de texto.
- **Detalles (SD):** Texto de menor jerarquía que brinda información adicional. Límite de tamaño mínimo en móvil (`SD`).
- **Detalles extra chico (XSD):** Está diseñado para textos de soporte con baja relevancia informativa. Se emplea principalmente en contenidos extensos de carácter legal o en notas de descargo de responsabilidad. Nota: Este estilo se utiliza únicamente en versiones de escritorio.

### Ejemplos de uso
Uso de diferentes jerarquías tipográficas dentro de un landing page.

### ¿Cómo leer la nomenclatura de las tipografías?
Consta de tres partes:
1. Uso
2. Número de acuerdo al tamaño: donde el número indica el tamaño. Entre más pequeño el número, más grande la tipografía.
3. Peso tipográfico
*(Ejemplo 1, Ejemplo 2)*

### Usos no permitidos
Para mantener coherencia y legibilidad en todos los materiales, evita los siguientes usos:
- No mezclar tipografías institucionales con fuentes externas.
- No alterar proporciones, pesos o estilos tipográficos fuera de los definidos.
- No aplicar efectos como sombras, contornos o deformaciones que afecten la claridad.
- No usar tipografías institucionales en contextos ajenos a su propósito (ejemplo: títulos legales con estilos de cuerpo de texto).

## 2. Diseño

### Patria
La tipografía Patria es una tipografía original del Gobierno de México que se utiliza para diseñar títulos y encabezados breves. Sus características son:
- Es de uso libre para el pueblo.
- Fue diseñada para esta administración del Gobierno de México y todas sus dependencias.
- Concentra la personalidad y el posicionamiento de la nueva administración.

## 3. Desarrollo

### Uso de tipografía en tu proyecto
En el marco del SND, la familia tipográfica predeterminada es **Noto Sans**. La familia **Patria**, destinada para utilizarla solo en encabezados, se invoca mediante la clase `.patria`.

Utiliza los encabezados `<h1>` a `<h6>` para establecer la jerarquía de tu página. Es importante que en cada página de tu proyecto mantengas una estructura semántica que ayude a la accesibilidad y al SEO (*Search Engine Optimization*).
- `<h1>` para el título de la página, el encabezado más importante. Solo puede haber un `<h1>` por página.
- `<h2>` para los títulos de las secciones.
- `<h3>` para las subsecciones.
- Y sucesivamente `<h4>`, `<h5>` y `<h6>` en caso de ser necesarios.

Es importante mantener la secuencia de los encabezados, es decir, no se debe pasar de `<h2>` a `<h4>`.
Para texto en general puedes usar elementos como párrafos `<p>`, contenedores de bloque `<div>` y contenedores de línea `<span>`.

```html
<h1 class="h0b">
  H1: Título de la página
</h1>
<h2 class="h1b">
  H2:Título Sección
</h2>
<h3 class="h2b">
  H3:Subtítulo
</h3>
<h4 class="sh0b">
  H4:Subtítulo
</h4>
<p class="b1">
  Un texto descriptivo
  <span class="b1b">
    con negritas.
  </span>
</p>
```

Los pesos tipográficos se indican con las siguientes terminaciones:
- `b` bold — (`font-weight:700`)
- `sb` semibold — (`font-weight:600`)
- `m` medium — (`font-weight:500`)
- `r` regular — (`font-weight:400`)

### Color
El color predefinido para el texto es `neutro800`. Para modificarlo, agrega la clase con el prefijo `.color--` seguida del color deseado. Consulta el apartado Colores para ver todas las clases disponibles que modifican el color del texto.

### Espaciado
Los estilos mencionados anteriormente incluyen un margen inferior de 16 pixeles. Para ajustar márgenes o rellenos, consulta las clases disponibles en este enlace.

# Sistema Nacional de Diseño (SND) – Plantilla: Medios de autenticación

- **Fuente:** https://www.snd.gob.mx/plantillas/integracion-llave-mx
- **Título de la página:** Medios de autenticación | Sistema Nacional de Diseño
- **Versión del SND:** 1.0.0 (`01/11/2026`)

Diseñada para permitir que el usuario se autentique usando un sistema externo. *(Esta página es informativa y no tiene pestañas Descripción/Diseño/Desarrollo ni bloques de código.)*

## Contenido

- **Barra de navegación:** Incluye la barra de navegación principal y segundaria, las cuales dan acceso a las secciones generales más importantes de la interfaz o plataforma.
- **Botón de idioma:** Permite al usuario cambiar el idioma de la página.
- **Título de la integración:** Texto que indica el nombre de la dependencia que aplica la integración.
- **Logotipo de la dependencia:** Imagen que indica el nombre de la dependencia que aplica la integración.
- **Tarjeta (card):** Agrupa todos los elementos necesarios para iniciar sesión, incluyendo radio botones para seleccionar medios de autenticación, casillas de verificación para enlaces externos y botones de acción. Integraciones: los medios de autenticación pueden realizarse con Llave MX, e.firma, correo o el sistema que la dependencia utilice.
- **Footer:** Proveé información complementaria y enlaces de soporte al final de la navegación sin distraer del contenido principal.
